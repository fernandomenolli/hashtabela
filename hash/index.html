HashTabela v1.2.0

Calcula o SHA-256 de arquivos no seu computador. Nada é enviado: sem internet, sem conta, sem rastreamento.

Nome de quem gerou a tabela.
Identificador livre do trabalho, para achar a tabela depois. Ex.: nº de protocolo, chamado ou caso interno.
De onde vieram os arquivos. Ex.: pendrive, HD externo ou celular modelo X.

Adiciona a data em que cada arquivo foi alterado pela última vez, segundo o sistema de arquivos. Cópias e downloads podem mudar essa data. Ao escolher uma pasta, mostra o caminho de cada arquivo dentro dela (ex.: fotos/img1.jpg) em vez de só o nome.

Resultado

Nenhum arquivo selecionado.

Arquivos até 256 MB usam a Web Crypto do navegador; maiores são lidos em blocos de 8 MB com SHA-256 em JavaScript (mais lento, mas sem limite de memória). Datas de modificação vêm do sistema de arquivos e podem não refletir a data original do conteúdo.
